HBM NTM Reforged는 원본 HBM's Nuclear Tech Mod의 Minecraft Forge 1.12.2 포트입니다.

이 프로젝트의 핵심 아이디어는 간단합니다. 원본 모드를 1.12.2로 가져오고 Extended Edition 콘텐츠와 합쳐서, 플레이어가 한 곳에서 최대한 완성된 경험을 할 수 있게 하는 것입니다. Extended Edition에서 좋아하던 것, 원본에서 그리웠던 것, 그리고 우주 콘텐츠까지 모두 하나의 모드에 담고 싶었습니다. 여러 fork와 에디션을 오가지 않아도 되도록요.

이것이 Reforged가 지향하는 방향입니다. 그 위에 다른 버전에는 없고 제가 개인적으로 보고 싶은 추가 콘텐츠도 작업 중입니다.
